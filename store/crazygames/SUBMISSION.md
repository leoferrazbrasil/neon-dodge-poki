## Game title

Neon Dodge

## Short description

Dodge the Glitches on a neon highway. One tap switches lanes. How long can you keep the signal alive?

## Long description

Neon Dodge is a one-tap arcade dodger. You guide NOVA, a courier carrying the Neon Core along an
unstable two-lane highway while Glitches corrupt the network ahead.

Every tap switches lanes. That is the whole control scheme, and there is nothing else to learn.
The difficulty rises on a fixed curve, so every run is a fair test of reaction and rhythm rather
than of luck.

Survive long enough and a beacon crosses the track. Each beacon unlocks a cosmetic reward on the
spot: new forms for NOVA, new colours, visual equipment and new environments. The Signal Meter in
the corner always shows how far the next unlock is, so you always know what you are playing for.
Progress is stored in your browser, and the collection screen lets you mix and match everything
you have earned.

No accounts, no timers, no purchases. Just the road, the Glitches and your reflexes.

## Controls

| Device | Action | Input |
| --- | --- | --- |
| Desktop | Start the run | Click, or press Space |
| Desktop | Switch lane | Click, or press Space, Arrow Up, Arrow Down |
| Desktop | Pause | P, or Escape |
| Touch | Start the run | Tap anywhere |
| Touch | Switch lane | Tap anywhere, or use the on-screen lane button |
| Touch | Pause | Pause button in the top bar |

Instructions shown to the player in game: **Tap to start** and **Each tap switches lanes**.
